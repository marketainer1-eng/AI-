# AI 에이전트 협회 아카데미 — GEO 과정 랜딩페이지

## 프로젝트 개요

AI 에이전트 협회 아카데미의 **GEO(Generative Engine Optimization) 과정** 단독 전환형 랜딩페이지입니다.  
SEO를 넘어 AI 기반 검색·추천 시대를 대응하는 GEO 전략을 배우고, 컨설턴트·강사 활동까지 확장할 수 있는 과정의 필요성과 실무성을 강하게 전달합니다.

---

## 구현된 기능

### 랜딩페이지 섹션 (12섹션)
1. **히어로 섹션** — 메인 헤드라인, 서브 카피, CTA 버튼 2개, 통계 배지, 파티클 애니메이션
2. **공지 배너** — 협회 공식 인증 과정 안내 배너
3. **과정 소개 (About)** — SEO vs GEO 비교 카드, 실전형 과정 강조
4. **왜 이 과정인가 (Why)** — 6개 이유 카드 그리드
5. **문제 해결 섹션** — 4가지 고민 → 해결 카드 구조
6. **커리큘럼 (6 STEP)** — 진단 → 전략 → 실행 → 확장 단계별 커리큘럼
7. **수강 후 결과물** — 6가지 산출물 카드 (즉시 활용 가능)
8. **협회 전용 지원 시스템** — GEO 진단 사이트, 전략 보조, 교재/강의안, 템플릿
9. **자격 및 활동 확장** — 수료 → 컨설턴트 자격 → 3방향 활동 (컨설팅/강사/대행)
10. **강사 인증 연결 구조** — 4단계 강사 인증 프로세스 + 지원 항목
11. **교육 + 대행** — "직접 배우거나 / 대행 맡기기" 분기 카드
12. **추천 대상** — 4가지 타깃 카드
13. **FAQ** — 7개 아코디언 FAQ
14. **최종 CTA** — 4개 CTA 카드 (강사 인증/자격/대행/상담)

### UI/UX 기능
- 고정 네비게이션 바 (스크롤 시 그림자 추가)
- 모바일 햄버거 메뉴
- 플로팅 "강사 인증 문의" 버튼 (히어로 섹션 지나면 표시)
- 스크롤 탑 버튼
- 부드러운 앵커 스크롤
- FAQ 아코디언
- IntersectionObserver 기반 스크롤 진입 애니메이션
- 히어로 파티클 애니메이션
- 패럴랙스 효과 (데스크탑)

```

css/
  style.css         — 전체 스타일 (협회형 네이비 브랜드 톤, 반응형)
js/
  main.js           — 인터랙션, 애니메이션, FAQ, 스크롤 효과
```

## 주요 진입 URI

| 경로 | 설명 |
|------|------|

| `/#curriculum` | 커리큘럼 섹션 |
| `/#support` | 협회 전용 지원 시스템 |
| `/#expansion` | 자격 및 활동 확장 |
| `/#instructor` | 강사 인증 연결 구조 |
| `/#agency` | 교육 + 대행 선택 |
| `/#target` | 추천 대상 |
| `/#faq` | FAQ |
| `/#final-cta` | 최종 CTA (강사 인증 문의 등) |
